\# UI\_UX — MiniCodex



\*\*Версия:\*\* 1.0 · \*\*Дата:\*\* 2026-11-09



Источник — раздел 7 HANDOFF.



\## Экраны



\### 1. «Библиотека»



\- Сетка карточек с превью (первый ракурс), lazy load + виртуализация.

\- Слева — дерево тегов и коллекции.

\- Сверху — поиск и фильтры (теги AND/OR, статус, формат, наличие фото покраса).

\- Hover: суммарный размер, полигоны, количество файлов (если >1), статус; Quick Actions («В слайсер», «В редактор», «В папке»); «вращение» 4 ракурсов при горизонтальном движении курсора.

\- Контекстное меню: копировать путь, удалить из библиотеки (файлы не трогаем), добавить тег, открыть карточку.



\### 2. «Карточка модели»



\- Слева — 3D-просмотрщик (вращение, зум, wireframe).

\- Справа — вкладки: Инфо / Файлы / Ассоциации / Теги / Заметки.

\- Кнопки: «Ориентировать», «Перегенерировать превью», «Открыть в слайсере», «Открыть в редакторе», «Показать в папке».

\- Конвертер масштабов (секция).



\### 3. «Настройки»



\- Папки-источники.

\- Корень ассоциаций (Hybrid, по умолчанию `./data/assets/`).

\- Пути к EXE слайсеров/редакторов + автодетект.

\- Тема (light/dark/auto), язык (RU/EN).

\- Обслуживание БД.



\## Горячие клавиши



| Клавиша | Действие |

|---|---|

| Ctrl+F | Поиск |

| Space | Быстрое превью |

| Enter | Карточка |

| Del | Удалить из библиотеки (файлы не трогаем) |



\## Локализация



Все строки — в `lang/en.json`, `lang/ru.json`. Ключи — `PascalCase.Category.Subkey`.
